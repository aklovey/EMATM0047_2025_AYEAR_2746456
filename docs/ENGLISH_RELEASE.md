# English-language release

This edition contains English documentation, filenames and presentation text. The compiled thesis PDF is omitted; the editable LaTeX source and figure PDFs remain.

Chinese passages in research notes and a small number of recorded prompt/reasoning fields were translated into English. Original factual and numerical statements, including mistakes in the recorded model reasoning, were preserved in those translations. The untranslated originals are retained in the private local archive.

Observed answers, scoring labels, request/question IDs, seeds, token usage and statistical results remain those of the original runs. A translated passage has different bytes and may have a different token count. Original text hashes and character offsets therefore refer to the original run, not to its English presentation. This release should not be used to claim byte-exact reconstruction or token recounting of translated passages.

Offline scoring and statistical recomputation use the preserved final responses and numerical fields. New inference using a translated demonstration would be a new experiment. The current-run TAR and historical verifier ZIP each contain the same release notice.

The document translations and the translated data are supplied for reading and analysis, with their original provenance retained. No model inference was rerun for this language-only update.
