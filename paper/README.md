# Dissertation LaTeX sources

This directory contains the editable LaTeX source, bibliography and compilation assets for the 11 September 2026 dissertation. The compiled thesis PDF is not included in the repository.

Compile `main.tex` with pdfLaTeX and BibTeX, or import this directory into Overleaf. The original school `dissertation.cls`, Computer Modern typography and two-sided chapter starts are retained.

The [evidence guide](../docs/EVIDENCE.md) maps the dissertation's E identifiers to the repository materials. [The figure directory](../figures/) provides editable diagrams and plotting sources. `paper/figures/` contains the graphics included by LaTeX. Experiment data and outputs are under [experiment/](../experiment/).
