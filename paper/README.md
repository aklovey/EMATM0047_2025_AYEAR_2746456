# Dissertation LaTeX sources

Editable sources for Yong Wang's eight-chapter MSc dissertation, *Demonstration Compression Inspired by Necessity and Sufficiency for Few-Shot Causal Reasoning*.

Compile `main.tex` with pdfLaTeX and BibTeX, or import this directory into Overleaf. The project includes the school dissertation class, logo, bibliography style and figures. Complete author metadata is retained in `references.bib`.

The manuscript has 27 main-text pages and 17 bibliography entries. `main.tex` controls the chapter order, including the system-exploration chapter.

The [evidence guide](../docs/EVIDENCE.md) maps the studies to repository materials. [Figures](../figures/) contains editable diagrams and plotting sources, and [experiment](../experiment/) contains the current evaluation data and saved outputs.
