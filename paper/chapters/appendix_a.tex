The code, evaluation data and supporting analyses for this dissertation are available in the project repository. Its README provides a guide to the materials.

Historical system evidence is indexed in the repository's system-exploration source register. The register links the system tables to preserved reports and distinguishes contemporaneous run records from later implementation snapshots. It also records the limits of the available attempt accounting and resource attribution.
