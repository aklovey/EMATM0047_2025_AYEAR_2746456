\section{The problem of reusable reasoning}\label{sec:1.1}

% WORKBENCH-ANCHOR p21-b003
In few-shot causal reasoning, a worked example can help a large language model (LLM) answer a causal question by showing which variables to condition on, which mechanisms an intervention changes, or how to evaluate a counterfactual. Long examples also occupy input context each time they are reused. The problem to solve is that compression must retain useful reasoning while removing repeated calculations, abandoned approaches and unnecessary restatements.

% WORKBENCH-ANCHOR p21-b004
Causal reasoning makes compression demanding because observational, interventional and counterfactual questions can involve the same variables but require different operations \cite{Pearl_2009,NEURIPS2023_631bb943}. A shortened trace may preserve its final answer while changing the estimand or omitting an essential assumption. A long trace could contain redundant steps. Zhu et al.\ observed that incorrect mathematical reasoning traces often continued to expand after early errors while remaining locally coherent \cite{zhu2026failure}. Length, answer correctness and semantic validity therefore require separate assessment.

% WORKBENCH-ANCHOR p21-b005
Few-shot in-context learning (ICL) uses a small number of demonstrations without updating model parameters. Chain-of-thought (CoT) prompting includes explicit intermediate reasoning in these demonstrations \cite{NEURIPS2022_9d560961}. Reusable compression raises two practical questions. How do shorter demonstrations compare with full demonstrations in answer accuracy and input and output token use on other causal questions? How does their construction effort compare with the reductions in input and output token use during reuse?

% WORKBENCH-ANCHOR p21-b006
I focus on the accuracy--input trade-off on CLADDER \cite{NEURIPS2023_631bb943}, using PNS to construct reusable demonstrations. Each selected demonstration retains a record of its parent text, intervention, continuation and acceptance decision. The construction record makes the compression process inspectable.

% EDIT-ANCHOR INT-SYSTEM-SCOPE
At the system level, a separate historical study compares reuse of saved first-pass model outputs and tool observations with a legacy multi-turn tool-agent workflow. The comparison evaluates the full tool-agent workflow separately from PNS demonstration compression.

\section{Research aim and questions}\label{sec:1.2}

% WORKBENCH-ANCHOR p21-b008
The central question is whether auditable trajectory compression improves the efficiency of few-shot causal reasoning. The evaluation measures strict answer accuracy and input and output tokens. It also measures the construction effort needed to obtain the demonstration bank.

% WORKBENCH-ANCHOR p21-b009
RQ1 asks how the complete construction-and-fallback policy compares with full demonstrations and length-matched heuristic compression in answer accuracy and input and output token use on other causal questions.

RQ2 examines how demonstration construction and checking effort compare with the reductions in input and output token use during reuse.

RQ3 asks how the selected shared-first-pass workflow compared with the legacy accumulated-history tool agent in answer accuracy, model-call counts and input and output token use. The clean-holdout comparison evaluates both systems on the same 974 questions in the historical GPT-5.5 study.

% WORKBENCH-ANCHOR p21-b010
The RQ1 comparison changes reasoning representations while holding demonstration identities, order and count fixed. 

% EDIT-ANCHOR INT-SUPPORTING-ANALYSES
The construction analysis asks whether continuation search can produce shorter demonstrations that have correct final answers and pass the specified audit checks. Semantic errors and recovery after an edit help explain the acceptance process. Incomplete cost records limit the answer to RQ2. RQ3 is addressed retrospectively through preserved system results under their original evaluation contracts.

\section{Contributions and research responsibilities}\label{sec:1.3}

% WORKBENCH-ANCHOR p21-b012
I set the research question and narrowed the study to CLADDER, with demonstration reuse as the main evaluation setting. I directed the scope and presentation of the dissertation, which focuses on the completed construction procedure and its two controlled evaluations. Codex assisted with drafting, code preparation and data analysis. ChatGPT 6 Pro assisted with drafting and editorial review.

% WORKBENCH-ANCHOR p21-b013
The project-specific work comprises the frozen demonstration bank, the controlled four-condition evaluation, reconstruction and source checks, and paired analyses. The project also provides an evidence package linking the reported results to saved responses. For the current compression experiments, CLADDER supplied the generator and reference material. Qwen3.6 supplied the generation model, and vLLM provided model serving. The contribution lies in the integration of these components into a traceable construction and evaluation workflow, including explicit handling of unsuccessful compression.
